# Comfort Zone Dental — Picshaw website concept

Buildless public source in `public/`. This is a speculative website concept for the Burbank practice. The practice has not commissioned or approved it.

The original website puts most service names in the doctor biography. This design gives general, restorative and cosmetic care distinct interactive paths, pairs the real owner portrait with a clear introduction, and adds an obvious first-visit journey and practical office details.

## Verification and limits

Official facts and asset provenance are recorded in `docs/`. No patient photos, ratings, reviews, clinical outcome or pain-free claims are invented. The portrait is the identified doctor on the official homepage. The practice should review all content and final image permissions before production.

The request form is a local demonstration. It does not transmit information, store information or book an appointment, and asks users to enter made-up details. It contains no medical-history or free-text field. Submission and page exit clear its entries. JavaScript attaches the handler before enabling submission.

Service tabs include arrow/Home/End keyboard navigation. FAQs use native disclosure elements. The mobile menu closes on navigation and Escape. Telephone links point to the published practice number.

The root agent adds the fixed server-side seven-day expiry, verifies deployment and creates the unsent Gmail draft. No deployment or branch mutation is performed by the site-builder agent.
