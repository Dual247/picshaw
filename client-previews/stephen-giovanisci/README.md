# Stephen J. Giovanisci, DDS — Picshaw concept

A buildless website concept for the Montrose practice. Source is `public/`; runtime expiry and deployment configuration are added by the owning agent.

The concept puts evening/Saturday office hours, the actual office, the two named dentists and clear care pathways ahead of the existing long service list. All facts and original image URLs are documented privately in `docs/`. The clinic has not commissioned or approved this design.

## Interactions

- Responsive mobile menu with Escape and link close
- Four accessible service tabs with arrow/Home/End keyboard navigation
- Native FAQ disclosure elements
- Demonstration request form; no network, persistence, free-text medical input or real booking; resets data after submit and pagehide
- Real telephone links clearly labeled

## Content limits

No reviews, ratings, credentials beyond verified degrees, specialty certification, success claims, prices, insurance participation or general-public emergency availability are invented. Photos depict the actual doctors and reception, from current practice website. Copy and assets require practice review before production.

Preview is labeled a Picshaw concept. `robots.txt` and meta directives prohibit indexing; live server gate provides fixed expiry.
